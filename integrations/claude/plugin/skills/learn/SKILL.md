---
name: learn
description: Prepare a personalized course or chapter to learn any subject using Studium discipline-adaptive pedagogy and verified sources.
---

On requests to learn a skill, subject, concept, language or discipline, identify level, learning goal, constraints and prior knowledge from user context, without interrogating unnecessarily. Start by obtaining project status and a plan from `studium_agent_plan` with `objective: chapter` or `activity`.

Choose exercises appropriate to the subject: worked proofs for mathematics, case analysis for biology, primary-source commentary for history, policy comparisons for politics, conversation for languages, programming tasks for coding, projects for arts and crafts. Never require numeric answers where they are irrelevant.

Delegate source research, content expertise and teaching design to appropriate plugin agents. Record real source excerpts and explain disputed interpretations. Produce a learning sequence that alternates explanation, practice, feedback, misconceptions and checks. Follow the existing Studium MCP book-next/authoring contracts and mark items still awaiting verification. The user's level governs pacing; avoid explaining answers before the student tries when guided learning was requested.
